# FAW RA 前端修改说明

本次仅提交到 `FAW-VW`，不修改或推送 `main`。与 RA 后端的 `doc/FAW-changes-20261026.md` 配套。

## 员工信息

- 后台同步提交后轮询任务状态，禁止重复点击，支持刷新后恢复查询。
- 失败和异常提示不再被当作同步成功；离开页面停止轮询。

## 员工证书

- 单条及批量分发复用现有任务和证书台账，显示发送中、渠道受理及失败原因。
- 分发提交不显示为已完成；列表与任务详情轮询最终状态，并展示签发和分发错误。
- 分发配置增加 SMTP 标识和 HTML 安装指引；模板保存实际消息类型。
- 移除不存在后端接口支持的任意分发 ZIP 上传；密码列表脱敏、台账导出不含密码。

## FAW 根证书台账

- 所属根筛选和指纹辅助区分同名根；链路抽屉展示真实多级签发关系及异常节点。
- 增加 CER/P7B 下载，JSON 错误响应不会被保存为证书文件。
- 仅有维护权限且属于手工导入的记录显示移除按钮，根证书移除明确提示关联中间证书范围。
- 同步存在错误或归属冲突时显示具体警告，不一律提示成功。
- 不修改 admin 根证书页面；菜单归属由配套后端菜单 SQL 维护。

## 验证与发布

- 最近一次对应检查：员工同步 3 项、员工分发 2 项、根证书台账 2 项通过。
- 已通过本地 RA 生产构建；本次提交不再次打包或部署，也不提交 dist、node_modules、测试运行结果或本地日志。
- 页面产物和后端需配套发布；新版本使用独立 FAW 镜像标签，避免覆盖已部署版本。
