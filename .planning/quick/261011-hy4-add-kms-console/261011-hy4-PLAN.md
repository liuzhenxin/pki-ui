# 新增 KMS 专属页面

用户要求：在 pki-ui 增加 KMS 专属页面，参考其他应用前端。沿用 Vue3、Element Plus、公共认证/权限与服务端菜单，产品租户固定为 2。liuzx-kms Phase 3 讨论保留，尚未确认 Locate 排序。

## 1. 类型化 API 与安全请求
新增 src/api/kms/{index,types}.ts、src/utils/kms.ts；仅调用现有 /kms/v1 端点。无列表接口，使用 UUID 查询。密码请求禁用公共重复提交缓存；公共 request.ts 仅对 KMS 错误作脱敏，避免打印包含请求体的 AxiosError。测试类型化契约、Base64/上下文校验及状态可用操作。

## 2. 控制台与入口
新增 src/views/kms/index.vue、components/{KeyDetail,CryptoPanel}.vue 和首页分发组件。菜单自动匹配 kms/index；租户 2 首页展示控制台。创建、详情、版本、启停/轮换/删除等待期、密码操作按既有权限和状态开放。敏感输入/结果只存页面内存，默认遮蔽明文结果，切换操作、关闭与卸载清空；异步返回不得复活已清除的数据。补充 KMS 标题/品牌和构建目标；KMS 不走 CA 初始化页。保留共享文件已有未提交改动，仅暂存本次增量。

## 3. 验证与交付
运行 KMS 专项 Vitest（API、页面权限、生命周期失败、敏感数据清理）、定向 ESLint、专属生产构建，浏览器检查桌面/窄屏。记录真实后端/网关未联调的边界。文档说明菜单、构建、OAuth 客户端及路由要求。只提交本次文件与共享文件增量，不推送。
