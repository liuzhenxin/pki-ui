# CSP 四步初始化前端

安装向导依次处理协议、环境检查、账号初始化和完成回执。协议复用 Agreement 组件。协议版本和权利主体从 CSP 服务读取。

系统管理员从平台登录后进入 `/csp/setup`，为预置系统管理员和审计管理员设置正式密码。CSP 主库保存进度、核验证据和提交尝试。完成请求携带服务端草稿版本及明确确认，经网关提交到 CSP 的 `/v2/setup/complete`。响应不确定时只查询状态，刷新或重新登录后继续以服务端的提交记录为准。

初始化完成后重新登录，系统管理员进入运行总览，其他角色按 CSP 返回的权限进入业务或审计页面。设备和密码资源配置在安装完成后执行。
